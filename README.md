# 🔐 DexVault

A secure and beginner-friendly **Password Manager** built using Python and Tkinter.
Stores credentials safely in a local JSON file with backup, search, and password generator features.

## ✨ Features
- Generate strong random passwords
- Save credentials securely
- Search and auto-copy to clipboard
- Show/Hide password toggle
- Duplicate and case-insensitive website handling
- Safe JSON handling with backup and atomic writes
- Works on macOS, Windows, and Linux

## 🛠️ Tech Stack
- Python 3
- Tkinter GUI
- JSON for storage
- Pyperclip (for clipboard)
